# Flashcards

A lightweight flashcard app for organizing decks and studying cards in the browser.

## Features

- Create, rename, and delete decks.
- Add, edit, and delete cards with validated front and back text.
- Search both sides of cards, case-insensitively.
- Study cards with flip, previous, next, and shuffle controls.
- Save decks and the active deck in browser local storage (`flashcards.state`).

## Run locally

Install dependencies and start the Angular development server:

```bash
npm install
npm start
```

Open `http://localhost:4200/`. The app reloads when source files change.

Run the production build and unit tests with:

```bash
npm run build
npm test
```

## Keyboard shortcuts

- `Space`: flip the current card.
- `Left Arrow`: previous card.
- `Right Arrow`: next card.
- `Escape` in the search field: clear the search.
